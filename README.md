# 🌸 Sakhi Smart Money

**Innovate4FinLit Game Challenge — Team Sudoku Gang**

🔗 Live Demo: http://sakhi-smart-money.netlify.app/

> A story-based financial literacy game where women learn money management by *living it* — budgeting smartly, fighting scams, and separating home and business money.

---

## 🚀 How to Use (Web)

1. Open the link in your browser
2. Tap the menu (☰)
3. Select **"Add to Home Screen"**
4. Use the app offline like a native app

---

## 🧠 Features

* 📅 12-month financial simulation game
* 💰 Money Jar allocation system
* ⚠️ Scam defense scenarios (OTP, QR, loan apps, KYC frauds)
* 🎭 Real-life events (medical, education, business)
* 📊 Progress tracking (financial health, debt stress, confidence)
* 🏆 Achievement badges
* 🌐 Offline-first functionality

## ⚙️ Installation & Setup (Local Run)

### 1. Prerequisites

* Install Flutter SDK: https://docs.flutter.dev/get-started/install
* Verify installation:

```bash
flutter --version
```

### 2. Clone the Repository

```bash
git clone <your-repo-link>
cd sakhi-smart-money
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run -d chrome
```
